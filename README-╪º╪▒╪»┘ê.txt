بچوں کا قاعدہ - اینڈرائڈ ایپ کا پروجیکٹ (عربی حروف)
===================================================

ایپ میں چار ٹیب ہیں:
1. حروف (ا ب ت): عربی کے 28 حروف۔ بچہ انگلی سے نقطوں پر لکھتا ہے، شاباش ملتی ہے اور حرف کی آواز آتی ہے۔
2. ملاپ (با تا): اوپر لکھا آتا ہے  ب + ا = با  (بے + الف = با)۔ پھر بچہ "با" نقطوں پر لکھتا ہے۔
   ب سے ی تک سارے 27 حروف الف کے ساتھ ملا کر سکھائے جاتے ہیں (با، تا، ثا، جا ...)۔
3. گنتی: ١ سے ١٠٠ تک، عربی ہندسے اور عربی لفظ (واحد، اثنان ...) کے ساتھ آواز۔
4. رنگ بھریں: تصویروں میں رنگ بھرنا، عربی نام (بطة، قمر، شمس ...) اور رنگوں کے عربی نام (أحمر، أزرق ...)۔

زبانیں وہی ہیں: اردو، English، العربية، فارسی، پښتو، سنڌي، हिन्दी (اوپر کونے میں)۔

APK بنانے کے دو طریقے
----------------------
طریقہ 1: اینڈرائڈ اسٹوڈیو (کمپیوٹر پر)
1. Android Studio مفت انسٹال کریں۔
2. File > Open سے یہ فولڈر (BachchonKaQaida) کھولیں۔ پہلی بار Gradle sync میں دس پندرہ منٹ لگ سکتے ہیں۔
3. Build > Build Bundle(s) / APK(s) > Build APK(s)۔
4. APK یہاں ملے گی: app/build/outputs/apk/debug/app-debug.apk
5. فون میں بھیج کر کھولیں اور "نامعلوم ذرائع سے انسٹال" کی اجازت دیں۔

طریقہ 2: گٹ ہب سے (کچھ انسٹال کیے بغیر)
1. github.com پر نئی repository بنائیں اور اس فولڈر کی ساری فائلیں اپلوڈ کریں۔
2. اگر .github فولڈر اپلوڈ نہ ہو تو Create new file سے .github/workflows/build-apk.yml بنائیں
   اور فائل build-apk.yml کا متن اس میں ڈال دیں۔
3. Actions ٹیب > Build APK > Run workflow۔
4. پانچ منٹ بعد Artifacts سے bachchon-ka-qaida-apk ڈاؤن لوڈ کریں۔

یہ ایپ پرانی انگلش ڈائری سے الگ انسٹال ہوتی ہے (الگ ایپ آئی ڈی: com.nanhe.qaida)۔

آواز کے بارے میں (بہت اہم)
------------------------
- عربی آواز فون کی Google Text-to-speech سے آتی ہے۔ فون میں عربی آواز انسٹال ہونی چاہیے۔
  ایپ میں نیچے "آواز (MP3) شامل کریں" کے حصے میں "عربی آواز انسٹال کریں" کا بٹن ہے جو فون کی
  ڈاؤن لوڈ کی سکرین کھولتا ہے۔ یا فون کی Settings > Text-to-speech > Google > Install voice data > Arabic۔
- "آواز کی جانچ" کا بٹن دبا کر دیکھ لیں کہ عربی آواز تیار ہے۔
- حرف کی آواز میں فون کی مشین کا لہجہ ہوتا ہے۔ بہترین طریقہ یہ ہے کہ کسی اچھے قاری/استاد/بچے کی آواز
  MP3 میں ریکارڈ کر کے ایپ کے اندر رکھ دیں (نیچے دیکھیں)۔ پھر فون کی مشین کی آواز کی ضرورت نہیں رہتی۔

اپنی MP3 آواز ایپ کے اندر شامل کرنا
-----------------------------------
فائلیں app/src/main/assets/audio/ میں ڈالیں، پھر دوبارہ APK بنائیں۔ نام (بڑے حرف، .mp3):
  L01 سے L28   : 28 حروف ترتیب سے
  S01 سے S27   : ملاپ (با، تا، ثا ... یا) ترتیب سے
  N1 سے N100   : گنتی
  W01 سے W26   : رنگ والی تصویروں کے الفاظ
  C_RED, C_ORANGE, C_YELLOW, C_GREEN, C_BLUE, C_PURPLE, C_PINK, C_BROWN : رنگوں کے نام
پورا نام اسی فولڈر کی NAMES.txt میں ہے۔ جو فائل نہ ہو اس کی جگہ فون کی عربی آواز چلتی ہے۔
ایپ چلنے کے بعد بھی نیچے "آواز (MP3) شامل کریں" سے فائلیں شامل ہو سکتی ہیں (نام: L01.mp3 وغیرہ یا RED.mp3)۔

فونٹ: Noto Naskh Arabic پہلی بار انٹرنیٹ سے آتا ہے۔ انٹرنیٹ نہ ہو تو فون کا اپنا عربی فونٹ چلتا ہے۔
