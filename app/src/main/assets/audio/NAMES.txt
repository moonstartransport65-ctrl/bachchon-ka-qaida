Put your MP3 files in this folder (audio). The app plays these first;
for any file that is missing it uses the phone's Arabic text-to-speech voice.
File names (capital letters, .mp3):

L01 - L28 : the 28 letters in order (ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي)
S01 - S27 : the joining lessons in order (با تا ثا جا حا ... يا)  [alif itself is skipped]
N1  - N100: numbers 1 to 100
W01 - W26 : the picture words in order shown in the Paint tab
C_RED C_ORANGE C_YELLOW C_GREEN C_BLUE C_PURPLE C_PINK C_BROWN : colour names
